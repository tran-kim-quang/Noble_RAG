RAG Service Quick Start Checklist
==================================

SETUP (First time only)
-----------------------
  [ ] Verify Docker and Docker Compose installed
      docker --version
      docker-compose --version

  [ ] Create .env file with LLM credentials
      Copy .env.example to .env
      Set LLM_API_KEY=your-openai-api-key
      Set other LLM_* variables as needed

  [ ] Build Docker images
      docker-compose build

  [ ] Start all services
      docker-compose up -d

  [ ] Wait for services to be healthy (30-60 seconds)
      docker-compose ps
      Should show all services as "healthy" or "Up"

  [ ] Verify RAG service is running
      curl http://localhost:8000/health
      Should return 200 with service info


FIRST TEST RUN
---------------
  [ ] Run test script
      python test/test_rag_service.py

  [ ] Expected output:
      - Service health check: PASS
      - Models info displayed: OK
      - Service status displayed: OK
      - Document uploaded: Success
      - Queries returned responses: OK

  [ ] Check service logs if any step fails
      docker-compose logs rag-service
      docker-compose logs postgres
      docker-compose logs qdrant


DOCKER SETUP CHECKLIST
----------------------
  [ ] PostgreSQL container running
      docker ps | grep postgres
      Should show noble_rag_postgres

  [ ] Qdrant container running
      docker ps | grep qdrant
      Should show noble_rag_qdrant

  [ ] Redis container running
      docker ps | grep redis
      Should show noble_rag_redis

  [ ] RAG service container running
      docker ps | grep rag-service
      Should show rag-service

  [ ] All containers on same network
      docker network ls | grep noble_rag_net
      Should show noble_rag_net bridge network

  [ ] Check database initialization
      docker-compose exec postgres psql -U rag_user -d noble_rag -c "\\dt"
      Should show any initialized tables


ENVIRONMENT VARIABLES CHECKLIST
--------------------------------

Required (for operation):
  [ ] LLM_PROVIDER set (openai, azure, ollama, gemini)
  [ ] LLM_API_KEY set (your actual API key)
  [ ] LLM_MODEL set (gpt-4o-mini, gpt-4, llama3.2, etc)

Optional (sensible defaults):
  [ ] EMBEDDING_MODEL (defaults to text-embedding-3-large)
  [ ] EMBEDDING_DIM (defaults to 3072 for OpenAI)
  [ ] CHUNK_SIZE (defaults to 1024)
  [ ] CHUNK_OVERLAP (defaults to 20)
  [ ] LOG_LEVEL (defaults to INFO)

Database URLs (auto-configured in docker-compose):
  [ ] POSTGRES_URL
  [ ] QDRANT_URL
  [ ] REDIS_URL


CLIENT CODE INTEGRATION CHECKLIST
----------------------------------

Python client in your code:

  [ ] Import RAGClient
      from client.rag_client import RAGClient, StorageType

  [ ] Initialize client
      client = RAGClient("http://localhost:8000")

  [ ] Check health before operations
      if not client.check_health():
          print("Service not available")

  [ ] Upload document
      result = client.upload_document(
          "path/to/document.txt",
          storage_type=StorageType.GRAPH
      )

  [ ] Query
      answer = client.query("Your question here?")

  [ ] Handle results
      if result:
          print(result['document_id'])
      else:
          print("Operation failed")


COMMON OPERATIONS
-----------------

Start fresh:
  docker-compose down -v    # Remove volumes
  docker-compose up -d      # Start fresh

Rebuild service:
  docker-compose build rag-service
  docker-compose up rag-service

View logs:
  docker-compose logs -f rag-service      # Follow logs
  docker-compose logs --tail=50 rag-service  # Last 50 lines

Database access:
  docker-compose exec postgres psql -U rag_user -d noble_rag

Stop services (keep volumes):
  docker-compose stop

Clean shutdown:
  docker-compose down

Remove everything:
  docker-compose down -v

TROUBLESHOOTING CHECKLIST
-------------------------

Service won't start:
  [ ] Check logs: docker-compose logs rag-service
  [ ] Verify .env has LLM_API_KEY set
  [ ] Check port 8000 not in use: lsof -i :8000
  [ ] Rebuild image: docker-compose build --no-cache rag-service

Health check fails:
  [ ] Wait 30 seconds (startup period)
  [ ] Check network: docker network inspect noble_rag_net
  [ ] Check service: docker-compose logs rag-service
  [ ] Verify single container: docker exec <rag_container> curl localhost:8000/health

Connection refused:
  [ ] Ensure container is running: docker ps | grep rag-service
  [ ] Check dependencies healthy: docker-compose ps
  [ ] Verify network: docker inspect noble_rag_net

Upload fails:
  [ ] Check file exists: ls -la path/to/file
  [ ] Check file readable: cat path/to/file
  [ ] Check service logs: docker-compose logs rag-service
  [ ] Test endpoint: curl -F "file=@test.txt" http://localhost:8000/upload-document

Query fails:
  [ ] Check document uploaded first
  [ ] Check API key in logs (LLM errors)
  [ ] Check query not empty
  [ ] Look for rate limiting errors

Database connection issues:
  [ ] Check PostgreSQL running: docker-compose logs postgres
  [ ] Test connection: docker-compose exec postgres pg_isready
  [ ] Check credentials match .env
  [ ] Verify init script ran: docker-compose logs postgres | grep init


PERFORMANCE OPTIONS
-------------------

For faster processing:
  [ ] Reduce CHUNK_SIZE to 512
  [ ] Reduce CHUNK_OVERLAP to 10
  [ ] Use StorageType.VECTOR only (if not need graph)

For better quality:
  [ ] Increase CHUNK_SIZE to 2048
  [ ] Increase CHUNK_OVERLAP to 50
  [ ] Use StorageType.BOTH (graph + vector)

For cost saving:
  [ ] Use cheaper model: LLM_MODEL=gpt-4o-mini
  [ ] Reduce top_k in queries (default 10)
  [ ] Process documents in batches
